# HSM — контекст мониторинга сенсоров

Контекст репозитория HSM (Hierarchical Sensor Monitoring). Существует параллельно с каноном `aicontext/glossary.md` в рамках триала навыков (см. `CLAUDE.md`, раздел Documentation Rules) — фиксирует термины, уточнённые в grilling-сессиях.

## Language

### Участники

**HSM-агент (Agent)**:
Автономный мониторинг-сервис на целевой машине (`hsm-agent.exe`, Windows; Linux probe), отправляющий данные сенсоров под access key продукта. Библиотека, встраиваемая в приложения, — это DataCollector, не агент.
_Avoid_: collector (для standalone-сервиса), «ИИ-агент» (другая сущность)

**ИИ-агент (оркестратор)**:
MCP-клиент (AI-ассистент), который провиженит HSM-ресурсы через management API/MCP и сам исполняет установку на целевой машине своими средствами. Сервер HSM никогда не исполняет код на целевых машинах.
_Avoid_: «агент» без уточнения в контексте, где возможна путаница с HSM-агентом

**Провижининг (Provisioning)**:
Часть процесса установки, которую делает сервер: создать продукт, выдать access key, отдать installer bundle. Противопоставляется исполнению установки, которое всегда происходит на целевой машине.

### Дерево

**Product (продукт)**:
Корневой узел дерева мониторинга, к которому привязываются access keys и HSM-агенты. Создатель продукта становится его автором (и менеджером по умолчанию).

### Креды

**Access Key**:
Пер-product-ный креденшел HSM-агента; сам ключ — это GUID, отправляемый в заголовке `Key`. Id ключа и есть секрет. Права — флаги `KeyPermissions` (CanSendSensorData, CanAddNodes, CanAddSensors, CanReadSensorData); состояние Active/Expired/Blocked.
_Avoid_: token, «ключ API»

**API Token**:
Персональный bearer-креденшел `hsm_pat_…` для `/api/v1` и MCP; зеркало прав владельца. Это НЕ то же, что access key агента.
_Avoid_: key, access key

### Установка

**Installer Bundle**:
Артефакт, который сервер генерирует по запросу: zip с подписанным `hsm-agent.exe` (Windows) или tar.gz с .deb (Linux probe) + `config.json` с адресом сервера и выбранным access key продукта + скрипты установки. Сервер генерирует и отдаёт бандл — сервер не является инсталлятором.
_Avoid_: «инсталлятор сервера», «голый .deb»
